Capabilities

Understands your project, not just your prompt.

Grace doesn't merely generate code. It inspects an existing project, understands the files, identifies problems, and explains what needs to be fixed — then writes the fix and verifies it.

01

Understands your codebase

Works with your existing project instead of treating every prompt like an isolated conversation. Grace reads files, maps structure, and acts in context.

02

Works in your terminal

A Python CLI and a full-screen Textual TUI built for developers who actually live in their terminal. No dashboard, no browser tab.

03

Built for real projects

Analyze files, identify problems, reason about code, run commands, and iterate until the task is done — with a clear report of exactly what changed.

Install

Up and running in seconds.

Install from the repository, then launch GRACE in any project folder. No API key required to start.

Step 1 — install 
# from the repository root
pip install .
Step 2 — run 
# in any project folder
grace

Optional — add a GROQ_API_KEY to .env or ~/.zeesh/env for fully local inference, or run grace register and grace login to use the hosted backend. See the README for details.
